# Smart Resume Analyzer

A Python and Streamlit-based ATS Resume Analyzer that helps users compare resumes with job descriptions and evaluate ATS compatibility.

#Features

- Resume PDF Upload
- Resume Text Extraction
- ATS Score Calculation
- Skill Detection
- Missing Skill Identification
- Job Description Matching
- Interactive Streamlit Interface

# Tech Stack

- Python
- Streamlit
- PDF Processing
- Text Analysis

# Future Improvements
